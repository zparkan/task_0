# دریافت تصادفی کتاب‌ها از Open Library

یک اسکریپت پایتون که اطلاعات **۵۰ کتاب تصادفی از موضوع‌های مختلف** را از API عمومی [Open Library](https://openlibrary.org/dev/docs/api/search) دریافت می‌کند، فقط کتاب‌هایی را که **سال انتشارشان بعد از ۲۰۰۰** است نگه می‌دارد و نتیجه را در یک **فایل CSV مرتب** ذخیره می‌کند.

این پروژه به‌عنوان تمرین کار با API، فیلتر کردن داده و نوشتن فایل در پایتون ساخته شده است.

## قابلیت‌ها

- دریافت داده از یک API عمومی (بدون نیاز به کلید API)
- انتخاب تصادفی موضوع‌ها و نقطه شروع، بنابراین هر بار اجرا نتیجه متفاوتی دارد
- حذف کتاب‌های تکراری
- حذف کتاب‌هایی که سال انتشارشان ۲۰۰۰ یا قبل‌تر است (یا سال انتشار ندارند)
- مرتب‌سازی نتیجه نهایی بر اساس سال انتشار
- ذخیره در `books.csv` با انکدینگ UTF-8 تا در اکسل درست نمایش داده شود
- مدیریت خطاهای شبکه بدون از کار افتادن برنامه

## پیش‌نیازها

- پایتون نسخه ۳.۹ یا بالاتر
- کتابخانه `requests`


## خروجی

پس از اجرا، فایل `books.csv` با ستون‌های زیر ساخته می‌شود:

| ستون | توضیح |
| --- | --- |
| `title` | عنوان کتاب |
| `subject` | موضوعی که کتاب از آن پیدا شده |
| `authors` | حداکثر سه نویسنده، جداشده با کاما |
| `first_publish_year` | سال اولین انتشار |
| `publisher` | اولین ناشر ثبت‌شده |
| `languages` | حداکثر سه کد زبان |
| `pages` | میانه تعداد صفحات (در صورت وجود) |
| `url` | لینک صفحه کتاب در Open Library |

توجه: اسکریپت ابتدا ۵۰ کتاب می‌گیرد و *بعد* فیلتر می‌کند، بنابراین تعداد سطرهای نهایی معمولاً کمتر از ۵۰ است.

## تنظیمات

همه تنظیمات در بالای فایل `fetch_books.py` قرار دارند:

| تنظیم | مقدار پیش‌فرض | توضیح |
| --- | --- | --- |
| `BOOK_LIMIT` | `50` | تعداد کل کتاب برای دریافت |
| `BOOKS_PER_SUBJECT` | `5` | تعداد کتاب از هر موضوع (عدد بیشتر = تنوع کمتر) |
| `MAX_RANDOM_OFFSET` | `100` | بیشینه نقطه شروع تصادفی در هر موضوع |
| `YEAR_THRESHOLD` | `2000` | فقط کتاب‌های بعد از این سال نگه داشته می‌شوند |
| `OUTPUT_FILE` | `books.csv` | نام فایل خروجی |
| `SUBJECTS` | ۳۰ موضوع | فهرست موضوع‌هایی که از بینشان انتخاب می‌شود |

## نحوه کار

1. **جمع‌آوری:** فهرست موضوع‌ها بُر زده می‌شود. برای هر موضوع، چند کتاب از یک نقطه شروع تصادفی درخواست می‌شود تا ۵۰ کتاب یکتا جمع شود.
2. **پاک‌سازی:** از نتیجه هر کتاب فقط فیلدهای لازم برداشته می‌شود.
3. **فیلتر:** کتاب‌هایی که سال انتشارشان ۲۰۰۰ یا قبل‌تر است (یا سال ندارند) حذف می‌شوند.
4. **مرتب‌سازی:** کتاب‌های باقی‌مانده بر اساس سال انتشار مرتب می‌شوند.
5. **ذخیره:** نتیجه در فایل CSV نوشته می‌شود.
